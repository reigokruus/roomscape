04 / Tech — what the code does

Native iOS.
RoomPlan + LiDAR.

01 / WORKS NOW

SetScan module

Swift + Apple RoomPlan. Live RoomCaptureView on LiDAR iPhone. Exports USDZ + JSON. SceneKit 3D / top view. Colors windows, doors, openings. Counts walls, natural-light windows, doors, furniture.

02 / PROTOTYPE

Planning layer

Web mockup: sample 2D room, draggable kit, illustrative 24/35/50 mm crops, encoded plan links. Concept for the next layer on top of the scan.

03 / ROADMAP

Shared shot plan

Import the SetScan room into a planner; sensor-aware framing; permissioned crew link. Not built yet.

Requires iPhone 12 Pro+ (LiDAR) · iOS 17+ · Xcode 15+. Built as SetScan.swiftpm — native, not a PWA scanner.

We do not claim photorealistic lighting, automatic light placement, or accurate 3D lens simulation today. Those are next.

05 / Competitors

Everyone owns a slice.
Nobody owns the loop.

Feature-closest overall: 3D previs, AR, LiDAR import, share links. Broader suite — Free / $39.99 mo / $119.99 yr (previspro.com).

Cadrage / Artemis

Lens-accurate FOV on the real (empty) location. No virtual lights or props in a scanned twin.

Polycam / Magicplan

Best-in-class room capture. No cinema FOV or film gear library on the dressed room.

Shot Designer

Trusted pocket blocking + shot lists. Diagram-first; no LiDAR room twin as the canvas.
